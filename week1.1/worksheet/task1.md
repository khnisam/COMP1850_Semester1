# Terminal Commands

You have been introduced to a variety of terminal commands this week – fill out the table with an explanation for each command which says what it is used for.

You may find it useful to run these commands in the terminal of Codespace to remind yourself.

You should put your explanations between the \| \| characters.

You can complete this task on the worksheet pdf if you prefer.

|     Command                 |     Explanation    |
|-----------------------------|--------------------|
|     pwd                     | shows the current location of the terminal |
|     ls                      | lists the files that are stored in the current directory |
|     cd directory_name       | moves into a directory called 'directory_name'|
|     cd ..                   | moves up one directory level|
|     cd -                    | moves back one directory level|
|     mkdir directory_name    | makes a new directory called 'directory_name' |
|     touch filename          | makes a new empty file called 'filename'|
|     git status              | this tells you what is currently happening in the Git repository |
|     git add -A              | this stages ALL changes made. It tells Git that you have work that you would like to save.|
|     git commit -m ""        | it will then bundle these changes into a 'commit' |
|     git push                | it will then send these changes back to the remote Github server |
|     git pull                | this will pull the saved changes from the Git remote server and into your virtual machine codespace |
